    확인 전

    새 설치 파일(ZIP 그대로도 OK)을 바탕화면 › Streamy Kit 업데이트 폴더에 넣으면 바로 위쪽에 업데이트 버튼이 떠요.

    문제 해결

    바꾸면 다시 시작한 뒤 적용돼요. 방송 화면(송출) 품질에는 영향 없어요.
