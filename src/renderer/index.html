    업데이트

    확인 전

    새 버전은 GitHub 릴리즈에 올라오면 5분 안에 알아서 받아서 적용돼요 (켤 때도 확인).
    바탕화면 › Streamy Kit 업데이트 폴더에 파일을 넣어도 몇 초 안에 적용돼요.
    빠른 업데이트(StreamyKit-Patch-…zip)는 윈도우 허용 창 없이 몇 초 만에 다시 켜지고, 설치 파일(Setup)은 허용 창에서 "예"를 눌러 주세요.

    문제 해결

    미리보기가 검게 가려지거나 이상하게 보이면 꺼 보세요. 끄면 엔진 기본 선택 표시로 바뀌어요.

    바꾸면 다시 시작한 뒤 적용돼요. 방송 화면(송출) 품질에는 영향 없어요.
