# Streamy 서비스 기획서

> 치지직 · 유튜브 · SOOP 스트리머를 위한 방송 도구 + 커뮤니티 + 홍보 플랫폼
> 최종 목표: 자본금 기준 **상원 MCN 설립**

---

## 1. 문제 정의

- 스트리머/시청자에게 **돈을 직접 받기 어렵다** — 아무도 돈 내고 쓰고 싶어 하지 않는다.
- 트위치 철수 이후 치지직 · SOOP · 유튜브로 흩어졌고, 스트리머 커뮤니티(트게더 같은 공간)와 방송 도구가 따로 논다.
- OBS는 강력하지만 초보에게 어렵다 — 독 세팅, 사운드 분리(디스코드/유튜브 소리 섞임), 버추얼 연결 등.

→ **기본은 무료**로 뿌리고, **광고 토큰 + 부가 기능(월 결제 / 영구제)** 으로 수익을 낸다.

---

## 2. 브랜드 / 서비스 구성

| 이름 | 역할 |
|---|---|
| **Streamy (스트리미)** | 전체 서비스 · 계정 · 토큰 · 메인 사이트 |
| **Streamy Kit (스트리미 킷)** | 방송 전용 프로그램 (이 저장소) |
| **Clubby (클러비)** | 게시판 / 커뮤니티 서비스. 앞의 "클"은 이용자(스트리머)에 따라 다르게 표시 — 서비스명은 Clubby로 고정, 표시 이름만 커스텀 |

- 지원 플랫폼: 치지직 · 유튜브 · SOOP 전용
- 도메인: 후이즈 등록 (연 2만 원 수준) — `streamy.kr` / `streamy.gg` / `getstreamy.com` 등 후보
- 디자인 톤: **블랙 · 레드** (Streamy Kit 기준)

---

## 3. Streamy 메인 사이트

### 메인 화면
- **스포트라이트** — 지금 방송 중인 스트리머: 크게 3칸, 그 아래 작게 5칸
- **클리피** (핫클립)
- 스트리머 홍보칸 · 홍보 배너
- 커뮤니티 인기글

### 메뉴
- 출석게시판 (토큰 지급)
- 방송 홍보 · 게임대회 홍보 (유저가 직접 개최 가능)
- 공지사항 · 건의

### 토큰 흐름
```
출석 / 광고 시청 ──▶ 토큰 ──▶ 스포트라이트 노출 · 홍보칸 · 기능 잠깐 해금
                      ▲
            (선택) 유료 구매
```
- 부계정 방지: 본인인증 또는 방송 채널 인증
- 스포트라이트 배분: 토큰 경매 / 시간제(1시간 단위) / 랜덤 순환 중 택1
- "방송 중" 정보와 클립은 각 플랫폼 API로 가져옴 → 약관 · 호출 제한 확인 필요

---

## 4. Clubby (커뮤니티)

- 스트리머별 커뮤니티 개설 (트게더 역할)
- 커뮤니티마다 **태그**로 글 분류, 유저가 관련 **갤러리 개설 신청 → 관리자 승인**
- 팬아트 · 클립 모음
- **영구제 꾸미기**: 스킨, 배너, 커스텀 표시 이름
- Streamy Kit 연동: 방송 켜짐/꺼짐 · 공지를 커뮤니티에 자동 게시, Kit 사용 스트리머에게 커뮤니티 자동 개설

---

## 5. Streamy Kit (방송 프로그램)

### 방향 결정 과정
1. **v0.1 — OBS 도우미**: 외부에서 OBS를 조작(WebSocket)해 세팅해 주는 프로그램 → OBS를 따로 설치해야 해서 "우리 프로그램" 느낌이 약함
2. **OBS 소스 수정(포크)**: 블랙·레드 테마로 리브랜딩까지 성공 → 윈도우 빌드에 Visual Studio가 필요하고, 화면 구조가 OBS에 묶임
3. **현재 — OBS 엔진 + 자체 UI** ✅: OBS의 방송 엔진만 가져오고 화면은 새로 만듦 (Streamlabs와 같은 방식)
   → 디자인 자유 + OBS급 성능 + 윈도우 설치 파일을 리눅스에서도 생성 가능

### 기능 목표
| 기능 | 상태 |
|---|---|
| 사용자 장면/소스 구성, 미리보기에서 끌기 · 크기 조절 | ✅ v0.3 |
| 들어오는 소리가 보이는 믹서 (레벨 막대) | ✅ v0.3 |
| 사운드 분리 (디스코드 · 유튜브 등 앱별) | ✅ |
| 보이는 타이머 | ✅ |
| 버추얼 바로 넣기 (Spout2) | ✅ |
| 치지직 · 유튜브 · SOOP 송출 프리셋, 그래픽카드 인코더 자동 | ✅ |
| 방송 설정 가이드라인 / 자동 방송 설정 | 예정 |
| AI 질문 → AI가 방송 배치 · 설정 (**카메라는 절대 건드리지 않음, 무조건 유저가 설정**) | 예정 (유료) |
| 독 / 채팅창 기본 제공 | 예정 |
| 전용 매니저 봇 (마스코트 "모찌") | 예정 |
| 무료 회원 / 유료 회원 | 예정 |

## 6. 수익 모델

| 구분 | 언제 돈을 받나 | 예시 |
|---|---|---|
| 무료 + 광고 | — | 기본 방송 기능, 기본 커뮤니티 |
| 광고 토큰 | 광고 시청 | 기능 하루 해금, 스포트라이트 |
| 월 결제 | 서버 비용이 계속 드는 기능 | AI 배치, 클라우드 백업, 매니저 봇, 멀티 송출, 통계 |
| 영구제 | 한 번 만들면 끝나는 것 | 오버레이 · 테마 팩, Clubby 꾸미기 |

- 초기에는 사용자가 적어 광고 수익이 작음 → **스트리머 대상 유료 기능**이 주 수입원이 될 가능성이 큼
- 경쟁: 트게더, 투네이션, 위플랩, Streamlabs — 차별점은 **"세팅부터 커뮤니티까지 한 번에, 한국 3대 플랫폼 전용"**

---

## 7. 라이선스 전략 (OBS 엔진 사용)

- OBS 엔진을 쓰면 **Streamy Kit 소스 공개 의무(GPL)** 가 생김 → 이 저장소로 공개
- 프로그램 판매는 가능하지만, 산 사람이 무료로 재배포할 수 있어 의미가 약함
- **서버 기능 · 계정 · 디자인 콘텐츠는 공개 의무 없음** → 수익은 여기서
- 제품명 · 로고에 "OBS" 사용 금지 (Streamlabs가 "Streamlabs OBS" 이름으로 분쟁 → "Streamlabs"로 변경한 사례)
- 장기: 사용자 · 매출이 생기면 자체 엔진으로 단계적 교체 검토

## 8. 실행 순서

1. ✅ Streamy Kit 프로그램 (무료 배포로 스트리머 확보)
2. ⏳ 윈도우 실기 테스트 → 버그 수정 → 코드 서명 → 공개 베타
3. Streamy 계정 + 무료/유료 구분
4. Streamy 메인 사이트 (출석 · 토큰 · 스포트라이트)
5. Clubby 오픈 (Kit 사용 스트리머 자동 개설 → 시청자 유입)
6. 유료화 (월 결제 · 영구제)
7. 상원 MCN 설립
